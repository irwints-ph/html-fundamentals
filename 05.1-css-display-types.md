# 🎨 CSS Display Types

The `display` property controls **how an element behaves in layout**.

---

# 📦 1. Block Elements

### 🔹 Behavior:

* Takes **full width** available
* Always starts on a **new line**
* You can set width/height

### 🧪 Example elements:

* `div`
* `p`
* `h1–h6`
* `section`

### 🧪 Example CSS:

```css id="b1zv9p"
div {
  display: block;
}
```

### 📌 Visual idea:

```txt id="d0c0b1"
[ BLOCK ELEMENT ]
[ takes full width ]
```

---

# 🧵 2. Inline Elements

### 🔹 Behavior:

* Takes only **as much space as needed**
* Does NOT start a new line
* Width/height usually ignored

### 🧪 Example elements:

* `span`
* `a`
* `strong`

### 🧪 Example:

```css id="k3m1aa"
span {
  display: inline;
}
```

### 📌 Visual idea:

```txt id="i2n9kk"
text [inline] text [inline]
```

---

### ⚠️ Limitation:

You cannot properly set:

```css id="q1x2zz"
width: 200px;
height: 100px;
```

---

# 🔳 3. Inline-block

### 🔹 Hybrid of block + inline

✔ Stays inline (same row)
✔ Allows width/height

### 🧪 Example:

```css id="v8p3ld"
button {
  display: inline-block;
  width: 120px;
  height: 40px;
}
```

### 📌 Use case:

* Buttons
* Navigation items

---

# 🧭 4. Flexbox (Modern Layout System)

### 🔥 Purpose:

To arrange items in **rows or columns easily**

---

## 🔹 Container setup:

```css id="f9k2aa"
.container {
  display: flex;
}
```

---

## 🔹 Default behavior:

Items go in a **row**

```txt id="r2x9cc"
[ item ][ item ][ item ]
```

---

## 🔧 Common flex properties:

### ✔ direction

```css id="d8a1bb"
flex-direction: row;    /* default */
flex-direction: column;
```

---

### ✔ spacing

```css id="s3k1pp"
justify-content: center;   /* horizontal */
align-items: center;       /* vertical */
```

---

### 🧪 Example:

```css id="f7m2qq"
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}
```

---

# 🧱 5. Grid (Advanced Layout System)

### 🔥 Purpose:

For **2D layouts (rows + columns)**

---

### 🧪 Example:

```css id="g2v9xx"
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}
```

### 📌 Visual:

```txt id="g1p8kk"
[ 1 ] [ 2 ] [ 3 ]
[ 4 ] [ 5 ] [ 6 ]
```

---

# ⚖️ Quick Comparison

| Type         | Behavior              | Use Case            |
| ------------ | --------------------- | ------------------- |
| block        | full width, new line  | layouts, sections   |
| inline       | flows in text         | links, spans        |
| inline-block | inline + size control | buttons             |
| flex         | 1D layout system      | navbars, centering  |
| grid         | 2D layout system      | dashboards, layouts |

---

# 🎯 Simple Rule of Thumb

* Need simple text styling → **inline**
* Need sections → **block**
* Need buttons in row → **inline-block or flex**
* Need alignment/center → **flex**
* Need complex layout → **grid**
